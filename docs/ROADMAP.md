# Roadmap

## V1 delivered

- Foundation and GitHub Pages-ready build configuration
- Cinematic single-page app shell
- Realistic 3D Earth rendering with atmosphere and cloud layer
- Full 3-axis mouse interaction
- URL-synced view sharing
- HUD telemetry, presets, fullscreen, and onboarding
- Unit tests, smoke E2E scaffold, and deployment workflow

## Next priorities

1. Place search and saved viewpoints
2. Country and city labels with decluttering
3. Optional data overlays such as borders, weather, or live layers
4. Better bundle splitting and texture compression
5. Expanded touch gesture support

## Explicitly deferred

- Backend persistence
- User accounts
- Paid map or geocoding APIs
- Terrain elevation and 3D extrusion
- Storytelling / scrollytelling article mode
